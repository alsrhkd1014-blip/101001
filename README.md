# 낚시 터치 보조 Android 프로젝트

이 프로젝트는 지정한 화면 좌표를 일정 간격으로 반복 터치하는 간단한 접근성 보조 앱의 소스입니다. 낚시 UI/타이밍을 인식하는 전용 매크로는 아니며, 게임 업데이트·화면 크기에 따라 좌표를 조정해야 합니다.

## APK 빌드 (PC 없이 GitHub Actions 사용)
1. 이 프로젝트 폴더의 파일을 GitHub 새 저장소에 업로드합니다.
2. 저장소의 **Actions** 탭에서 **Build APK** 워크플로를 선택하고 **Run workflow**를 누릅니다.
3. 완료된 작업의 Artifacts에서 `EggFishingMacro-debug-apk` ZIP을 다운로드하고 압축을 풀어 `app-debug.apk`를 설치합니다.
4. Android 설정에서 앱의 접근성 서비스와 화면 위 표시 권한을 직접 허용합니다.

## 사용
1. 앱에서 터치 X/Y와 간격을 입력합니다. 좌표는 화면 픽셀 기준이며 기본값은 예시입니다.
2. 화면 위 시작/정지 버튼 표시를 누릅니다.
3. Roblox를 열고 오버레이의 START를 누릅니다. 닫기 버튼은 반복을 중지하고 오버레이를 제거합니다.

## 중요
- 소스 프로젝트이며 이 파일 자체는 APK가 아닙니다. APK는 위 GitHub Actions에서 빌드해야 합니다.
- Android 접근성 권한은 강력한 권한입니다. 본인이 검토한 소스만 설치하고, 신뢰하지 않는 APK는 설치하지 마세요.
- 게임의 이용 규칙에 따라 매크로 사용은 계정 제재 위험이 있습니다. 게임 규칙을 확인하고 책임 있게 사용하세요.
